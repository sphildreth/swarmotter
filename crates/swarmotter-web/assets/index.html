Compatibility

Autopilot

Storage

State-directory changes require restart. The NOCOW option is explicit, never changes existing files, and fails on unsupported filesystems rather than falling back.

Storage root controls

Controls use the most-specific matching path. Zero leaves a limit unlimited; existing work can finish safely while later admissions use the new controls.

Network containment

SOCKS5 TCP proxy

Off by default. Peer TCP, HTTP(S) trackers, and webseeds connect through this proxy after the proxy itself is reached through the contained network path. Target hostname resolution is remote through SOCKS5. SOCKS5 UDP is not supported: enabling it requires disabling uTP and DHT, and UDP tracker URLs are refused rather than sent directly.

Listen-port reachability test

Off by default. Configure an HTTP(S) endpoint you operate; the request is made through the contained torrent network path and only reports an informational result.

Router port mapping

Off by default. Requires strict, fail-closed containment and a required interface. Discovery and lease requests use that same contained path; an unavailable router never changes torrent operation.

Policy profiles

Profiles apply named storage, queue, seeding, bandwidth, and optional encryption_mode defaults. Storage paths are captured when a torrent is added; other profile fields remain live for inheriting torrents.

Use profiles for named definitions and labels to map labels to a profile. Save Settings validates the configuration before applying it.
